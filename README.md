# Alraqi Store | متجر الراقي

متجر إلكتروني ثنائي اللغة (عربي + إنجليزي) بتصميم راقي وحديث.

## المميزات

- ✅ تصميم داكن أنيق بألوان ذهبية فاخرة
- ✅ دعم كامل للعربية (RTL) والإنجليزية (LTR)
- ✅ تبديل اللغة بنقرة واحدة مع حفظ الاختيار
- ✅ سلة تسوق تعمل بـ LocalStorage
- ✅ صفحات: الرئيسية، المنتجات، تفاصيل المنتج، السلة، من نحن، تواصل معنا
- ✅ متجاوب بالكامل (موبايل + تابلت + ديسكتوب)
- ✅ فلترة المنتجات حسب الفئة

## طريقة التشغيل محلياً

1. افتح مجلد المشروع
2. افتح ملف `index.html` في المتصفح  
   أو استخدم Live Server في VS Code

## النشر (Deployment)

### Cloudflare Pages (موصى به)
1. ارفع المجلد على GitHub
2. ادخل إلى [Cloudflare Pages](https://pages.cloudflare.com)
3. اربط الريبو واختر الفرع
4. اترك إعدادات البناء فارغة (Static site)
5. انشر → سيعطيك رابط مثل `alraqi.pages.dev`

### Vercel / Netlify
- نفس الفكرة: ارفع الملفات كـ Static Site

## تخصيص المنتجات

عدّل ملف `js/products.js` لإضافة أو تعديل المنتجات.

كل منتج يحتوي على:
- الاسم بالعربي والإنجليزي
- السعر والسعر القديم (للخصم)
- الفئة (new / bestsellers / luxury / sale)
- الوصف
- التقييم والمخزون

## الدومين

بعد النشر يمكنك ربط دومين مخصص:
- `alraqi.com` (تحقق من التوفر أولاً)
- أو أي دومين تشتريه من Namecheap / GoDaddy / Cloudflare Registrar
